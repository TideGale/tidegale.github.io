# tidegale.github.io

作品集主页，单页静态站，纯 HTML 加内联 CSS，没有构建步骤，改完直接提交就好。

线上地址 https://tidegale.github.io/

## 改什么

只改 `index.html` 一个文件。

- 项目进度变了：改「做过的事」里对应那段，加实测数字时先确认是程序自己打出来的，不是估的
- 新项目：复制一个 `<article>`，套同一套结构，写完把链接换成新仓库
- 「没做完的部分」不许删空，没做完就在那写着，面试官看得出来

## 为什么不用框架

一页纸的东西上 Jekyll 或 Next 只会让改一个数字要跑一次构建。纯 HTML 打开就能改，手机也能看。
