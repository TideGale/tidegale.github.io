# tidegale.github.io

个人作品集主页。单页静态站，纯 HTML 加内联 CSS，没有构建这一步。

线上：https://tidegale.github.io/

## 改哪里

只动 `index.html`。

- 项目进度变了，改「做过的事」里对应的那段。加数字之前先确认是程序自己打出来的，估的不要写
- 加新项目，复制一个 `<article>`，结构照旧的，链接换成新仓库
- 「没做完的部分」不能删空。没做完就写在那，面试官看得出来

## 为什么不用框架

一页纸的东西上 Jekyll 或 Next，改一个数字要跑一次构建。纯 HTML 打开就能改，手机也能看。
